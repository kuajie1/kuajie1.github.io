# 第九卷 · 歌曲卷

本卷收录《冰雪奇缘》两部正片中的全部代表性歌曲，每首均提供完整英文原词与中文译文，并接入官方原声（FLAC 无损）。译文支持「对照 / 悬停 / 隐藏」三种模式（点击歌曲卡片右上角按钮切换）。音频文件位于 audio/frozen1/ 与 audio/frozen2/，页面会在加载成功后自动隐藏占位提示。卷末另设「歌词考据」与「角色动机映射」专章，从文本层面解析歌曲与剧情的互文。（来源：Disney 官方原声带 / Frozen Wiki 歌词校核）
