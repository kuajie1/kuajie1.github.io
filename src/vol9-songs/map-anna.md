# 安娜：连接、纽带与行动

- **《For the First Time in Forever》**与**《Do You Want to Build a Snowman》**——动机是"对连接与姐妹纽带的渴望"，前者是加冕日的 outward 期盼，后者是童年被隔离的 inward 呼唤。
- **《The Next Right Thing》**——动机是"低谷中的行动力"，在失落洞窟以一步一行重建自我，成为其执政哲学。

Kristoff 的**《Lost in the Woods》**从男性视角反向映射安娜之于他人的意义——"没有 Anna 的人生"令人迷失。（来源：《电影1艺术设定集》· 第13页；《电影2艺术设定集》· 第120页；《Frozen 2 官方电影特刊》· 第59章）
