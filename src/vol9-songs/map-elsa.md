# 艾莎：从释放到寻真

- **《Let It Go》**——核心动机是"自我接纳与释放"：从 conceal 到 let it go，完成 Snow Queen 身份确立。
- **《Into the Unknown》**——动机转向"责任 vs 使命召唤"的内心挣扎，呼应其"protector"定位。
- **《Show Yourself》**——动机升华为"追寻身世真相"，在阿塔霍兰与父母的记忆和解，坐实第五灵身份。

三曲构成艾莎从"隐藏自我→回应召唤→揭示真相"的动机弧线。（来源：《电影1艺术设定集》· 第16页；《电影2艺术设定集》· 第38、142、147页）
