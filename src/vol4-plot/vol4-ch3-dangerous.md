# 伊杜娜与阿格纳的一生（依《危险秘密》）

《Dangerous Secrets》以"序章/尾声的海上风暴"为框架，倒叙父母从相遇到遇难前夜的完整一生；全书事件均在电影1之前，序章船难即电影1开场父母葬身大海之夜。时间锚点：第一章 "Twenty-Six Years Earlier"，伊杜娜船难时约 38 岁、艾莎约 21 岁，与 Frozen 1 父母死于艾莎加冕后约三年相吻合。

- 北境**伊杜娜出生与童年**：伊杜娜生于魔法森林的北境人（Northuldra），被长老祝福为"太阳之子"；5 岁时亲生父母在"入侵者"事件中被杀，藏身母亲所织四精灵披肩下被北境妇女收养。（来源：《危险秘密》· ch.21 梦境回溯）
- 大坝庆典**救阿格纳与流落**：伊杜娜 12 岁、阿格纳 14 岁，Runeard 献坝庆典上阿伦黛尔人与北境人交战、Runeard 跌落大坝身亡，伊杜娜用风之灵 Gale 救出受伤的阿格纳，自己落入阿伦黛尔，被误认为阵亡的阿伦黛尔女孩。（来源：《危险秘密》· ch.1–ch.3）
- 孤儿院**重逢与相恋**：阿格纳苏醒知父王战死、Peterssen 摄政；月后于孤儿院与伊杜娜重逢，多年同窗情谊渐深、终成眷属。（来源：《危险秘密》· ch.4–ch.13）
- 密室**生石谷与身世坦白**：二人循阿格纳生母 Rita 的地图找到山巨魔，巨魔从北极光预见"生两女"；伊杜娜最终向阿格纳坦白自己是救他的北境人，认定女儿艾莎是"精灵之礼"。（来源：《危险秘密》· ch.15 / ch.31）
- 姐妹诞生**魔法初现与意外**：长女 Elsa 襁褓中向转铃射出冰；次女 Anna 出生后，一夜游戏里 Elsa 失手以冰击中 Anna 头部，巨魔施救抹去记忆、留一缕白发，城堡闭门谢客。（来源：《危险秘密》· ch.26 / ch.27 / ch.45）
- 最后航行**驶向 Ahtohallan 遇难**：以"赴远方公主婚礼"为掩护，二人登船驶向 Dark Sea / Ahtohallan，途中遇风暴船沉，临终幻见长大的 Elsa 与 Anna 相视而笑——即《冰雪奇缘》开场事件。（来源：《危险秘密》· Prologue / Epilogue / ch.32–33 / ch.46–48）
