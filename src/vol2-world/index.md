# 第二卷 · 世界观与地理


本卷梳理《冰雪奇缘》两代故事的虚构地理：自峡湾王国阿伦黛尔（Arendelle）向北，经「雾之穹顶」进入魔法森林（Enchanted Forest），抵达北境民族（Northuldra）领地；再向北跨越暗海（Dark Sea），抵达记忆冰川阿塔霍兰（Ahtohallan）；并收录城堡、峡湾、北山等节点，以及南方群岛、威斯顿、维斯特兰等周边王国。所有条目均标注来源（官方电影、艺术设定集、官方小说与粉丝维基），存疑处注明「待考证」。 （来源：Disney 官方 / Frozen (2013) / Frozen II (2019)）
